# カラオケレパートリー管理アプリ UI 仕様書

Claude Design で高忠実度プロトタイプを生成するための指示書。MVP コア 6 画面を定義する。

---

## 0. プロダクト概要

### 何を作るのか

DAM カラオケで歌った自分の採点履歴（精密採点 Ai）を取り込み、個人の歌唱データを一元管理する Web アプリ。レパートリー管理・採点履歴の集計とグラフ化・セットリスト作成・レコメンドを1つに統合した「歌う人のためのダッシュボード」。

### 利用者と利用シーン

- 単一ユーザー向けの個人ツール
- **スマホ**: カラオケ店でのレパートリー検索、セトリ確認、次に歌う曲の判断
- **PC**: 帰宅後の履歴レビュー、セトリ作成、長期的な上達分析

### 技術スタック（参考情報）

- フロント: Next.js App Router + TypeScript
- UI: Tailwind CSS
- DB: Supabase (Postgres)
- データ取得: DAM の非公式 XML API から採点 Ai 履歴を取得
- ホスティング: Vercel

## 1. デザインシステム

### トーン

**カラオケらしいネオン・リッチな雰囲気**。DAM の精密採点 Ai 結果画面のような、ダーク基調にネオンの光が走るテイスト。ただしデータ管理ツールとしての読みやすさを優先する（装飾で情報を覆わない）。

### カラーパレット

```
--bg-base:        #0a0a14   /* 最下層の背景、深い紺黒 */
--bg-surface:     #13132a   /* カード背景 */
--bg-elevated:    #1c1c3a   /* モーダル・ドロワー等 */
--border:         rgba(255, 255, 255, 0.08)
--border-strong:  rgba(255, 255, 255, 0.16)

--text-primary:   #ffffff
--text-secondary: rgba(255, 255, 255, 0.72)
--text-muted:     rgba(255, 255, 255, 0.48)

--neon-pink:      #ff2a8a   /* 最高点ハイライト、ヒーロー要素 */
--neon-cyan:      #00e5ff   /* セカンダリアクセント、リンク */
--neon-purple:    #a855f7   /* 補助アクセント */
--neon-green:     #00ff9d   /* 成功・達成系(90+点など) */
--neon-amber:     #ffb300   /* 注意・80-90点帯 */

--gradient-hero:  linear-gradient(135deg, #ff2a8a 0%, #a855f7 50%, #00e5ff 100%)
```

### 発光 (glow) の使い方

重要な数値（最高点、Ai ボーナス、レーダーチャートのピーク）にのみ glow を適用。使いすぎると画面全体がボケるので、1 画面で glow する要素は 1〜2 個に制限。

```css
.neon-text-pink { text-shadow: 0 0 12px rgba(255, 42, 138, 0.6), 0 0 24px rgba(255, 42, 138, 0.3); }
.neon-text-cyan { text-shadow: 0 0 12px rgba(0, 229, 255, 0.6); }
.neon-border-pink { box-shadow: 0 0 16px rgba(255, 42, 138, 0.4), inset 0 0 8px rgba(255, 42, 138, 0.1); }
```

### タイポグラフィ

- 見出し: Inter または system font、太字
- 数字（得点・日時）: タビュラ数字フォント（`font-feature-settings: "tnum"`）で桁揃え
- 点数の大型表示: 80-120px、weight 700、ネオン glow 付き

### レイアウト原則

| 画面幅 | レイアウト |
|---|---|
| 〜767px (モバイル) | ボトムナビ、1 カラム、要素を大きめ（タップ領域 64px 以上） |
| 768px〜 (タブレット/PC) | サイドバー、2〜3 カラム可、データ密度高め |

Tailwind breakpoint は `md: 768px` で切り替える。

### 共通コンポーネント

- **ナビゲーション**: モバイルはボトムナビ固定、PC は左サイドバー固定。項目は順に「ホーム」「レパートリー」「履歴」「セトリ」「設定」
- **カード**: 背景 `bg-surface`、border 1px、角丸 12px、padding 16px。hover 時に border を `border-strong` に変化
- **スコアバッジ**: 点数を目立たせる小型コンポーネント。90+ はネオンピンク glow、80-90 は白、<80 はミュート
- **ヘッダー**: 画面タイトル（左）、検索/フィルタアイコン（右）。モバイルでは sticky top

### 避けるもの

- 絵文字の多用、マイク/音符アイコンの過剰装飾
- ライトモード（ダーク専用で OK、トグル不要）
- 過度な半透明ぼかし（glassmorphism は控えめに）


**要素詳細**:

- **検索バー**: 虫眼鏡アイコンタップで展開。曲名・アーティストを横断検索
- **フィルタチップ**: 横スクロール可。アクティブ時はネオンピンク枠。複数選択は不可（排他）
- **並び替え**: 「最高点順」「追加日順」「最終歌唱日順」「曲名順」
- **曲カード**: タップ領域 64px 以上。カード内構成は上段に曲名（白・太字）、中段にアーティスト（グレー）とキー調整（例: +2 / 原キー / -3）、下段にタグチップと自信度、最終歌唱日。右上に最高点のネオンピンク数字
- **自信度**: 3 段階（得意=★★★、普通=★★☆、練習中=★☆☆）。ユーザー設定
- **FAB**: 右下に固定。タップで曲マスタ追加モーダル

**状態**:

- レパートリー 0 件時: 「まだレパートリーがありません。採点履歴から追加するか、手動で追加してください」と案内、2 つのアクションボタン
- 検索結果 0 件時: 「該当する曲がありません」とクリアボタン

**遷移**:

- カードタップ → 画面3 レパ詳細
- FAB → 曲マスタ追加モーダル（→採点履歴から追加 or 手動追加）

### 画面3: レパートリー詳細 / 編集

**パス**: `/repertoire/[id]`

**目的**: 1 曲の情報を深掘り、メタ情報（キー、タグ、メモ）を編集。

**レイアウト (モバイル)**:

```

│ [ヘッダー]                     │
│ [←]  詳細          [編集]      │
├────────────────────────────────┤
│ [曲情報ヒーロー]               │

├────────────────────────────────┤
│ [メインスコアカード]           │
│ ┌────────┬────────┬────────┐   │
│ │ 最高点 │ 直近点 │ 平均点 │   │
│ │ 90.298 │ 90.298 │ 87.560 │   │ ← 最高はネオンピンク
│ └────────┴────────┴────────┘   │
├────────────────────────────────┤
│ [小型レーダーチャート]         │
│     音程 83                    │
│  安定 80  ╱╲  表現 81          │
│         ╱  ╲                   │
│  リズム98  ビブラート75        │
│  タップで拡大                  │
├────────────────────────────────┤
│ [音域]                         │
│ 曲の音域:   D3 ━━━━ D#5        │
│ 自分の声域: D3 ━━━━ D#5        │
├────────────────────────────────┤
│ [メタ情報]                     │
│ キー設定:     原キー (0)       │
│ 自信度:       ★★★☆☆           │
│ タグ:         J-POP / バラード │
│ メモ:         サビ前のブレス   │
│               注意。最後落ちる │
├────────────────────────────────┤
│ [歌唱推移ミニグラフ]           │
│ 直近10回の点数推移（折れ線）   │

│ [この曲の履歴をすべて見る >]   │
│ [レパートリーから削除]         │
└────────────────────────────────┘
```

**要素詳細**:

- **音域表示**: 鍵盤風の横バー。MIDI note 番号を音名変換して表示（D3, D#5 など）。音域データがない場合は「未測定（歌うと自動で記録されます）」と案内。`vocalRangeHighest/Lowest`（曲）と `singingRangeHighest/Lowest`（自分）を 2 本並べて差分を可視化
- **レーダーチャート**: 5 項目（音程・安定性・表現力・ビブラート&ロングトーン・リズム）。直近歌唱値を使用。タップで拡大してモーダル表示
- **メタ情報**: 閲覧モードでは表示のみ。編集アイコンで編集モードに切替。編集モードは保存/キャンセルボタンが出る
- **歌唱推移**: X 軸日時、Y 軸点数。点をタップで該当履歴にジャンプ

**編集モード**:

- キー: スライダー -6 ～ +6
- 自信度: セグメント 3 択
- タグ: チップ複数選択、新規タグ追加可
- メモ: textarea

**遷移**:

- レーダー拡大 → モーダルで詳細レーダー＋Ai 感性グラフ
- 「履歴をすべて見る」→ 曲別履歴画面（将来 #7）
- 削除 → 確認モーダル → 画面2 に戻る

- **合計バー**: 曲数と予想総時間（1 曲 4 分と仮計算でも OK）を sticky 表示

**遷移**:

- 曲追加 → レパートリー選択モーダル
- 保存 → 画面8 に戻る

## 4. プロトタイプ生成時の注意

### Claude Design に伝えたいこと

- **画面ごとに個別生成する**。一気に 6 画面作らせると散漫になる
- **スマホ/PC 両対応**。各画面でモバイルビューと PC ビューの両方を見せる
- **ダークモード固定**。ライトモードトグルは不要
- **日本語**。すべての UI テキストは日本語
- **数値のリアリティ**。`90.298` のような小数点以下 3 桁まで。80-90 点台の曲も混ぜて現実味を出す
- **アーティスト名例**: Official髭男dism、米津玄師、YOASOBI、あいみょん、Mrs. GREEN APPLE、優里、Saucy Dog、スピッツ、宇多田ヒカル、星野源など J-POP 中心。特定の実在曲名を並べることで生活感を出す

### 優先順位

最初に生成すべきは以下の順:

1. 画面2 レパートリー一覧（アプリの顔）
2. 画面3 レパートリー詳細
3. 画面1 ダッシュボード
4. 画面5 採点履歴一覧
5. 画面8 セットリスト一覧
6. 画面9 セットリスト編集

### 避けてほしいこと

- マイク・音符・星などのカラオケイメージ絵文字の多用
- リアルな写真素材（アバター、ジャケット等）の埋め込み
- ライトテーマ
- アニメーションの多用（派手さで情報が埋もれる）
- カード要素を角丸なし・大きなシャドウ（モダンさを損なう）

## 5. 拡張予定機能（MVP 後、設計時考慮）

以下は MVP には含めないが、データ構造は対応できるようにしておく:

- 採点履歴詳細画面（24 区間グラフ、Ai 感性グラフ、レーダー大表示）
- 曲別スコア推移（時系列での上達可視化）
- オススメ曲提案（Claude API にレパ+履歴を投げて提案）
- 音源アップロード → 音域自動解析（歌ってない曲の音域を自前計算）
- 声域マップ（MIDI note ベースで自分の得意音域を可視化）

これらの機能が後から追加される前提で、データモデルとナビゲーションに余地を残しておく。
