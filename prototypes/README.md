# Claude Design プロトタイプ

Claude Design で作成した各画面のビジュアルリファレンス。

## 配置するファイル

以下のスクショをこのフォルダに配置してください:

- `01-repertoire-list.png` - レパートリー一覧（モバイル）
- `02-dashboard.png` - ダッシュボード（モバイル、2 枚）
- `03-repertoire-detail.png` - レパートリー詳細（モバイル、2 枚）

## 使い方

- UI 実装時のビジュアルリファレンス
- 仕様書（`docs/karaoke-app-design-spec.md`）と食い違いがある場合は**仕様書を真実の情報源**とする
- Claude Design の Hand off URL がある場合は、URL を優先（プロトタイプはそちらに含まれる）

## 注意

- スクショは実装のゴールではなく**参考イメージ**
- データのモック値はスクショのまま使わず、実データに差し替えること
- Claude Design 側で 5 点の改善を自発提案した要素（下記）は特に覚えておくこと:
  1. **ヒーローカードの「自己ベスト更新」バッジ**（仕様書に逆反映推奨）
  2. **音域バーの鍵盤風ベースレイヤー**（紫グラデ + シアン重ね）
  3. **「最近歌唱値」ラベル付きレーダー**
  4. **自信度の「★★☆ + 普通」併記**
  5. **取り込みカードの「精密採点 AI 履歴」サブラベル**
